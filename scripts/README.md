# سكريبتات إدارة المخزون

## نظرة عامة

هذه السكريبتات تساعد في إدارة حالة المخزون لمنتجات الشرايح والراوترات.

## السكريبتات المتوفرة

### 1. mark-products-out-of-stock.js

**الوظيفة:** جعل جميع منتجات الشرايح والراوترات نفذت الكمية، مع استثناء المنتجات التي مدة اشتراكها سنة أو 6 أشهر.

**كيفية التشغيل:**

```bash
npm run mark-out-of-stock
```

أو

```bash
node scripts/mark-products-out-of-stock.js
```

**ما يقوم به السكريبت:**

1. يبحث عن جميع المنتجات المتوفرة في المخزون
2. يفحص كل منتج للتحقق من أنه شريحة أو راوتر (من خلال الاسم، الفئة، أو الفئة الفرعية)
3. يتحقق من مواصفات المنتج للبحث عن مدة الاشتراك
4. إذا كانت مدة الاشتراك سنة أو 6 أشهر، يتم استثناء المنتج
5. باقي المنتجات يتم تحديثها إلى `inStock: false`
6. يعرض ملخص تفصيلي للعملية

**الكلمات المفتاحية للشرايح والراوترات:**

- شريحة، شرايح، sim، سيم
- راوتر، روتر، router

**التأثير:**

- يتم إخفاء زر "أضف للسلة" تلقائياً
- يتم منع عمليات الشراء للمنتجات الغير متوفرة
- يظهر للمستخدم "نفذت الكمية"

---

### 2. restore-products-stock.js

**الوظيفة:** إرجاع جميع منتجات الشرايح والراوترات لحالة متوفر (عكس السكريبت الأول).

**كيفية التشغيل:**

```bash
npm run restore-stock
```

أو

```bash
node scripts/restore-products-stock.js
```

**ما يقوم به السكريبت:**

1. يبحث عن جميع المنتجات الغير متوفرة
2. يفحص كل منتج للتحقق من أنه شريحة أو راوتر
3. يرجع المنتجات إلى حالة `inStock: true`
4. يعرض ملخص تفصيلي للعملية

## متطلبات التشغيل

### 1. التأكد من وجود ملف `.env`

يجب أن يحتوي على:

```env
MONGODB_URI=your_mongodb_connection_string
```

### 2. تثبيت الحزم

```bash
npm install
```

## أمثلة على مواصفات المنتجات

لكي يتم استثناء منتج، يجب أن يحتوي على مواصفات مثل:

```javascript
specifications: [
  {
    groupName: "تفاصيل الاشتراك",
    items: [
      { label: "مدة الاشتراك", value: "سنة" },
      // أو
      { label: "مدة الاشتراك", value: "6 أشهر" }
    ]
  }
]
```

**القيم المدعومة للاستثناء:**

- سنة، سنه
- ١٢ شهر، 12 شهر
- 12 month، 1 year
- ٦ أشهر، 6 أشهر، 6 شهور
- 6 month

## ملاحظات هامة

### الأمان

- السكريبتات تعمل مباشرة على قاعدة البيانات
- يُنصح بعمل نسخة احتياطية قبل التشغيل
- السكريبت الأول يمكن عكسه باستخدام السكريبت الثاني

### التحقق

- السكريبت يعرض قائمة بجميع المنتجات المحدثة
- يمكنك مراجعة النتائج قبل أن يتم إغلاق الاتصال

### التخصيص

إذا كنت تريد تعديل:

- **الكلمات المفتاحية:** عدّل دالة `isSimCardOrRouter()`
- **قيم مدة الاشتراك:** عدّل دالة `hasValidSubscription()`
- **المعايير الإضافية:** أضف شروط جديدة في السكريبت

---

## استكشاف الأخطاء

### خطأ في الاتصال بقاعدة البيانات

```
❌ خطأ في الاتصال بقاعدة البيانات
```

**الحل:** تحقق من:

1. ملف `.env` موجود ويحتوي على `MONGODB_URI`
2. قاعدة البيانات تعمل ويمكن الوصول إليها
3. بيانات الاتصال صحيحة

### لا يوجد منتجات تم تحديثها

```
✅ عدد المنتجات التي نفذت الكمية: 0
```

**السبب المحتمل:**

1. لا توجد منتجات شرايح أو راوترات في قاعدة البيانات
2. الكلمات المفتاحية لا تتطابق مع أسماء المنتجات
3. جميع المنتجات بالفعل `inStock: false`
