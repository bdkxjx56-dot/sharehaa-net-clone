# دليل الاستخدام السريع

## 🚀 البدء السريع

### الخطوة 1: المعاينة (بدون تعديلات)

قبل إجراء أي تغييرات، شاهد ما سيتم تحديثه:

```bash
npm run test-detection
```

هذا الأمر سيعرض لك:
- ✅ المنتجات التي ستنفذ كميتها
- ⏩ المنتجات التي سيتم استثناؤها
- ➖ المنتجات الأخرى التي لن تتأثر

**⚠️ لن يتم إجراء أي تعديلات - فقط معاينة!**

---

### الخطوة 2: تطبيق التغييرات

بعد التأكد من النتائج، قم بتشغيل:

```bash
npm run mark-out-of-stock
```

هذا الأمر سيقوم بـ:
- ✅ جعل جميع الشرايح والراوترات نفذت الكمية
- ⏩ استثناء المنتجات التي مدة اشتراكها سنة أو 6 أشهر
- 🚫 منع زر الشراء والإضافة للسلة تلقائياً

---

### الخطوة 3: الإرجاع (إذا احتجت)

إذا أردت إرجاع المنتجات لحالة متوفر:

```bash
npm run restore-stock
```

---

## 📋 الأوامر المتاحة

| الأمر | الوصف | آمن؟ |
|------|-------|------|
| `npm run test-detection` | معاينة المنتجات بدون تعديلات | ✅ نعم |
| `npm run mark-out-of-stock` | تطبيق نفاذ الكمية | ⚠️ يعدّل البيانات |
| `npm run restore-stock` | إرجاع المخزون | ⚠️ يعدّل البيانات |

---

## 🎯 مثال على سير العمل

```bash
# 1. افحص المنتجات أولاً
cd backend
npm run test-detection

# 2. إذا كانت النتائج صحيحة، طبّق التغييرات
npm run mark-out-of-stock

# 3. إذا احتجت للتراجع
npm run restore-stock
```

## ⚙️ التحقق من إعدادات المشروع

قبل التشغيل، تأكد من:


## 📊 فهم النتائج

### مثال على مخرجات المعاينة:

```
📊 ملخص المعاينة:
================================================================================
✅ منتجات ستنفذ كميتها: 15
⏩ منتجات ستُستثنى (لديها اشتراك سنة أو 6 أشهر): 8
➖ منتجات أخرى (ليست شرايح أو راوترات): 142
📦 إجمالي المنتجات: 165
```

**تفسير:**
- **15 منتج** سيتم تحديثهم إلى نفذت الكمية
- **8 منتجات** لن تتأثر (لديها اشتراك سنة أو 6 أشهر)
- **142 منتج** آخر لن يتأثر (ليسوا شرايح أو راوترات)

## ⚠️ تحذيرات هامة

### قبل التشغيل:
1. ✅ اعمل نسخة احتياطية من قاعدة البيانات
2. ✅ شغّل `test-detection` أولاً للمعاينة
3. ✅ تأكد من صحة النتائج

### بعد التشغيل:
- يمكنك التراجع باستخدام `restore-stock`
- راجع المنتجات على الموقع للتأكد
- السكريبت آمن ولا يحذف أي بيانات

---

## 🆘 استكشاف الأخطاء

### لا يوجد منتجات تم تحديثها؟

**الأسباب المحتملة:**
1. لا توجد منتجات تحتوي على الكلمات المفتاحية
2. جميع المنتجات لديها اشتراك سنة أو 6 أشهر
3. جميع المنتجات بالفعل `inStock: false`

**الحل:**
- شغّل `test-detection` لفهم ما يحدث
- راجع أسماء وفئات المنتجات في قاعدة البيانات

### خطأ في الاتصال بقاعدة البيانات؟

```
❌ خطأ في الاتصال بقاعدة البيانات
```

**الحل:**
1. تحقق من ملف `.env`
2. تأكد من تشغيل MongoDB
3. تحقق من صحة رابط الاتصال
